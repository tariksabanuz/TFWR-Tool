# TFWR-Tool
"The Farmer Was Replaced" game on Steam to help you with your own save!

__It contains the following options:__
1. Option 1 has the name "Edit a save". If you choose this option, it will ask which save and what you want to change. You can choose between every single farmable and the amount you want.
2. Option 2 is called "Unlock everything in a save". When choosing this, it will ask which save. After choosing one, it will replaced the save.json file with everything unlocked, so you can say it's creative mode.
3. The name of option 3 is "Leaderboard run". If you are an expert, or want to speedrun certain things, then choose this option. It will unlock everything in the game and it will add 2 python files that contains the code to start the speedrun.
